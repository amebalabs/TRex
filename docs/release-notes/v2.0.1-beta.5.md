# TRex v2.0.1 Beta 5 Release Notes

This beta brings the native macOS selection crosshair to frozen-screen capture and tidies the onboarding setup page.

## Fixes

- Frozen-screen selection now uses the native macOS selection UI on top of the frozen screen, so the crosshair appears as it does with freezing turned off. Previously the pointer could stay an arrow. (#116, #110)
- Fixed the onboarding Quick Setup page cutting off the permissions step inside a small scroll area, aligned the section tabs, and corrected the button label to "Open System Settings". (#117)

## Changes

- With frozen-screen selection, the capture sound now follows the capture sound setting, and pressing Space selects the whole frozen screen instead of a single window. (#116)

## Known Issues

- Apple's accurate OCR model can still stall intermittently, which can delay results by several seconds. (#115, #106)
- Frozen-screen selection with the native selection UI has been tested on a single display only and still needs confirmation on a physical multi-monitor setup. (#110)

Requires macOS 14 or later. Includes support for Apple Silicon and Intel Macs.
